# ПВЗ

Откройте `index.html` в браузере или запустите проект через локальный HTTP-сервер. Сборка не требуется. Подключение к Supabase задаётся в `js/config.js`.

- Выберите растения перед уровнем. Во время боя нажмите на карточку растения, затем на свободную клетку. Лопата удаляет своё растение.
- Растения атакуют автоматически, подсолнухи дают солнце. Волна заканчивается после уничтожения всех её зомби. Прорыв к дому означает поражение.
- В бесконечном режиме «Новая игра» сразу запускает слот. Кнопка «Сохранить и выйти» записывает поле, солнце, врагов и состояние волны; «Продолжить» восстанавливает их. При закрытии вкладки без этой кнопки несохранённый прогресс теряется.
- В лобби все участники нажимают «Готов». Ведущий рассчитывает общее поле, остальные получают его состояние через Supabase Realtime. Солнце общее; выход ведущего завершает матч. Держите вкладку ведущего открытой и активной.

## Структура проекта

- `index.html` — разметка экранов и порядок подключения файлов.
- `css/styles.css` — оформление и адаптивные стили.
- `js/config.js` — создание клиента Supabase.
- `js/data.js` — растения, зомби, локации и сложности.
- `js/state.js` — общее изменяемое состояние игры и сетевых подключений.
- `js/utils.js` — экранирование HTML и цвета игроков.
- `js/screens.js` — переключение экранов и заглушка мини-игр.
- `js/auth.js` — регистрация, вход, выход и профиль.
- `js/campaign.js` — карта уровней и выбор растений.
- `js/game/board.js` — запуск игры, отображение поля, посадка и лопата.
- `js/game/simulation.js` — солнце, зомби, атаки, волны и завершение игры.
- `js/chat.js` — интерфейс и отправка сообщений чата.
- `js/online.js` — список лобби, сложности и онлайн-игроки.
- `js/lobby.js` — вход и выход из лобби, готовность и подписки.
- `js/match.js` — синхронизация совместного матча.
- `js/saves.js` — слоты бесконечного режима и сохранения.
- `js/main.js` — инициализация приложения.
- `tests/` — проверки логики и интерфейса.

Используются обычные браузерные скрипты с общей областью видимости: это сохраняет работу при открытии через `file://` и существующих обработчиков `onclick`. Сначала загружаются конфигурация, данные и состояние, затем функции приложения, последним — `main.js`. Тесты считывают этот же порядок из HTML. Новые общие переменные следует объявлять в `state.js`, справочные данные — в `data.js`.

## Проверки

Node.js 18+; тесты логики не требуют установки зависимостей и не обращаются к рабочей базе:

```sh
node --test tests/game.test.cjs
```

Проверка интерфейса требует установленного Playwright и Chromium:

```sh
node tests/browser-smoke.cjs
```

При необходимости `PLAYWRIGHT_MODULE` задаёт путь к модулю Playwright, `CHROME_EXECUTABLE` — путь к Chrome. `PVZ_SCREENSHOT` задаёт путь для снимка экрана. Браузерный тест подменяет Supabase, чтобы не создавать аккаунты и не менять данные.
